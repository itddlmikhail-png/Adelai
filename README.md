# Adelai

**AI Operating System**

Репозиторий содержит:

- `Adelai/` — iOS приложение (SwiftUI) — в паузе
- `web/` — маркетинговый сайт / лендинг — **текущий фокус**

## Сайт

```bash
cd web
npm install
npm run dev
```

Открой http://localhost:3000

## iOS

Открой `Adelai.xcodeproj` в Xcode 15.4+ (iOS 17), когда вернёмся к приложению.
